## Запуск

Python 3.12. Из папки `wine_app`:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m streamlit run app.py
```

## Кэширование

`st.cache_resource` сохраняет загруженную модель в памяти. При следующих действиях пользователя приложение использует тот же объект. Без декоратора `joblib.load` читал бы файл заново при каждом перезапуске скрипта.

`st.cache_data` хранит таблицу test.csv и рассчитанные вероятности. При получении из кэша данные копируются, поэтому изменения в одном запуске не затрагивают сохранённое значение. Сдвиг порога меняет только сравнение вероятностей с порогом.
